Veritabanı Kurulumu (tek seferlik)
Supabase Bağlantısı
Tüm kullanıcıların aynı verileri görmesi için bulut veritabanı gerekli. Bu kurulum tek seferlik yapılır.
1
supabase.com → Sign Up → New Project oluştur (tamamen ücretsiz)
2
Sol menü → SQL Editor → New Query → aşağıdaki kodu yapıştır ve Run:
create table if not exists app_users ( username text primary key, name text not null, role text not null default 'user', pass_hash text not null, created_at timestamptz default now() ); create table if not exists candidates ( id text primary key, name text not null, role text not null, phone text, email text, location text, experience text, notes text, applied_date text, status text default 'in-progress', rounds jsonb default '[]', created_at timestamptz default now(), updated_at timestamptz default now() ); alter table app_users disable row level security; alter table candidates disable row level security;
3
Project Settings (sol alt dişli) → API → Project URL ve anon public key'i kopyala
Baglanti bilgileri yalnizca tarayicinizda saklanir. Ayarlari sifirlamak icin bunu tiklayabilirsiniz: Ayarlari Sifirla
